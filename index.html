설교 노트

설교의 속도를 따라가는 필기. 구절 자동 인용, 신앙 기호 레일, 흐름 도식 — 예배 중 필기를 위해 만든 iOS 노트 앱입니다.

주요 기능

  • "요 3:16" 타이핑 → 성경 본문 자동 인용 (개역한글, 오프라인)
  • 신앙 기호 원터치: θ · χρ · πν · ε · ✝︎ 및 필기 기호
  • 본문 주소 입력 시 [오늘의 본문] 자동 로드
  • 텍스트 한 줄 → 박스 다이어그램 도식화
  • 핵심 메시지 · 미니스트리(찬양) 기록, 찬양 제목 자동완성
  • 모든 데이터 기기 내 저장 — 계정·서버·광고 없음
